# LeagueHub — Gestor de Liga Deportiva

Aplicación web SPA para gestionar ligas deportivas amateur multi-deporte, con dos modalidades de torneo (liga y eliminación directa), estadísticas, gráficos y persistencia local en IndexedDB.
